# applications-repository

This repository serves as a central directory for all our applications and projects. Every new project or significant update should be documented here.

## Purpose

- Maintain a comprehensive list of all applications
- Track project status and key information
- Provide quick access to repositories and documentation
- Archive completed or deprecated projects

- [Active Applications](./applications/active/)

## Application Categories

### By Status
- 🟢 **Active** - Currently maintained and in use
- 🟡 **In Development** - Under active development
- 🔵 **On Hold** - Temporarily paused
- ⚫ **Archived** - No longer maintained

### By Type
- Landing Pages
- Websites
- Internal Tools
- APIs/Libraries/Automation

## How to Update

### Adding a New Application
1. Create a new issue using the "New Application" template
2. Fill in all required information
3. Wait for review and approval
4. The application will be added to the directory

### Updating an Existing Application
1. Create an issue using the "Update Application" template
2. Specify the changes made
3. Update will be reviewed and merged
